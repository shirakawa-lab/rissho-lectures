# 座位姿勢AIチェック（scratch-ml-001）

座った姿勢の正面写真・横向き写真をPoseNetで解析し、関節点と簡易評価を表示する教材です。

## 学習目標

- 姿勢推定が画像から関節座標を取得する仕組みを理解する。
- 座標差、絶対値、比率、条件分岐をScratchの考え方と結び付ける。
- AIの出力は測定条件や信頼度に影響されることを理解する。

## 評価項目

- 正面：左右の肩の高さ、頭と肩中心のずれ
- 横向き：耳と肩の位置、肩と腰の位置

## 注意

本教材は機械学習の教育用デモです。医療上の診断や治療判断には使用できません。

モデルはTensorFlow.jsとPoseNetを外部CDNから読み込むため、初回実行時にはインターネット接続が必要です。写真自体を教材サーバーへアップロードする処理はありません。
