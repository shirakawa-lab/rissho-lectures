# rissho-lectures

立正大学データサイエンス学部の公開ページ（GitHub Pages）。

## 収録コンテンツ

- `Scratch_model/` — Scratch・機械学習のブラウザ実行型教材集
  - `sitting-posture-posenet/` — 座位姿勢AIチェック（PoseNet）
- `arcGIS_model/` — 全国 市町村別 人口マップ（自己完結型HTML・外部通信なし）
- `kumagaya_population/` — 熊谷市 町丁別 人口マップ
