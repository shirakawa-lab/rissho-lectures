# rissho-lectures

立正大学データサイエンス学部の公開ページ（GitHub Pages）。

## 収録コンテンツ
- `arcGIS_model/` — 全国 市町村別 人口マップ（自己完結型HTML・外部通信なし）
- `kumagaya_population/` — 熊谷市（埼玉県）町丁別 人口マップ（令和2年国勢調査 小地域）
- `kamaishi_population/` — 釜石市（岩手県）町丁別 人口マップ（令和2年国勢調査 小地域）
- `yachiyo_population/` — 八千代市（千葉県）町丁別 人口マップ（令和2年国勢調査 小地域）
- `yokohama_population/` — 横浜市（神奈川県）町丁別 人口マップ（令和2年国勢調査 小地域・18区）
- `fukuoka_udon/` — 福岡市 うどん店マップ（7区色分け・全317店を店名/住所つきでプロット）
